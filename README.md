# AIチャットアプリ — 大瓜生山祭2026

京都芸術大学・大瓜生山祭2026の「プログラミング演習」の授業展示用に、学生制作のチャットボットを紹介する1ページの静的サイトです。GitHub Pages での公開を想定しています。

**現在の20作品はレイアウト確認用のサンプルです。本番展示前に実際の作品情報へ差し替えてください。** 展示教室は未確定です。

## ファイル構成

```text
index.html            ページ本文・展示概要
theme.css             配色・書体・カードサイズなどのデザイントークン
styles.css            レイアウト・レスポンシブ対応
data.js               作品データ（主な更新箇所）
script.js             カテゴリ絞り込み・作品紹介ダイアログ
assets/favicon.svg    サイトアイコン
.nojekyll             Jekyll の処理を無効化
AGENTS.md             コントリビューター向けガイド
```

外部ライブラリ、API キー、ビルド、依存関係のインストールは不要です。

## デザインを変える

公式ポスターの赤とクリームのストライプ、青緑、黄色、黒い影を参考にした仮デザインです。ポスター画像自体は使用していません。

配色・書体・角丸・余白・カード画像の高さは `theme.css` の変数でまとめて変更できます。ページ構成やカードの並び方を変える場合は `styles.css` を編集します。作品データの編集は不要です。

iPad でのタッチ操作を想定し、ヘッダー直下に短いアプリ紹介を置いて、縦向き・横向きとも作品を4列で配置します。作品数は `data.js` の登録数に応じて変わり、表示件数も自動更新されます。ボタンは高さ44px以上を確保しています。スマートフォンでは2列です。詳しい説明は作品をタップしたダイアログで読みます。

## ローカルで確認

Python 3 を使用します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

<http://127.0.0.1:8000> を開きます。停止は `Ctrl+C`。

## 作品を登録する

`data.js` の `window.EXHIBITION_WORKS` に作品を追加・編集します。

```js
{
  id: "work-01",                     // 重複しない識別子
  title: "作品名",
  category: "発想",                   // 相談・発想・物語
  tagline: "一覧に表示する短い紹介文。",
  description: "作品のねらいや楽しみ方。",
  prompt: "最初に話しかけてほしいひとこと。",
  author: "表示する制作者名",
  visual: "lime",                    // lime / lilac / orange / pink / blue / yellow
  symbol: "✳",
  url: "https://example.com/chatbot", // 実際に公開済みの HTTPS URL
  sample: false,
}
```

`sample: true` または URL 未設定の場合、チャットボットへのリンクは表示されません。作品情報はテキストとして描画されます。公開してよい制作者名と URL を登録してください。

全サンプルを差し替えたら、`index.html` の `.sample-notice` を更新・削除してください。授業名・展示タイトルは `index.html`、ブラウザのタイトル・説明も同じファイルで編集します。カテゴリを増やす場合はフィルターボタンも追加してください。

## GitHub Pages で公開

1. このフォルダの内容を GitHub リポジトリの `main` ブランチへ push します。
2. リポジトリの **Settings → Pages → Build and deployment** を開きます。
3. **Source: Deploy from a branch** を選び、**main / (root)** を保存します。
4. Pages のデプロイ完了後、表示された公開 URL を確認します。

ファイルは相対パスで参照するため、`https://<owner>.github.io/daiuryuzansai-2026/` のようなプロジェクトサイトに対応します。以降は `main` の更新で再公開されます。GitHub Pages の公開可否はアカウントのプランとリポジトリの可視性に依存します。

## 動作確認

自動テスト、リンター、カバレッジ基準は未設定です。更新時は以下を確認します。

- PC・スマートフォンの幅でレイアウトに横スクロールがない。
- 各カテゴリで表示件数と作品が切り替わる。
- 作品紹介を開閉でき、`Escape` で閉じると元のボタンにフォーカスが戻る。
- キーボードで操作でき、外部リンクが新しいタブで開く。
- 実作品のリンク先が正しく、サンプルが残っていない。
